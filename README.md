# Obowiązkowe wyposażenie auta w Europie

Prosta aplikacja: wybierz kraj i sprawdź, jakie wyposażenie samochodu jest w nim obowiązkowe, a jakie zalecane – w formie kafelków z ikonami i listy do spakowania.

Dane: plik `wyposazenie.csv` (29 krajów europejskich). Informacje orientacyjne – przed wyjazdem sprawdź aktualne przepisy kraju docelowego.

Zbudowane w Pythonie i Streamlit.
